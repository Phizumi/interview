# React 面试核心基础问题（10 个）

## 1. 什么是 React？它的主要特点是什么？

**答案：**

React 是一个用于构建用户界面的 JavaScript 库，由 Facebook 开发。

**主要特点：**

- **组件化**：将 UI 拆分成独立、可复用的组件
- **声明式**：只需描述 UI 应该是什么样子，React 会自动更新 DOM
- **虚拟 DOM**：在内存中维护一个虚拟 DOM 树，提高性能
- **单向数据流**：数据从父组件流向子组件，便于追踪和调试

**举例：**

```jsx
// 声明式：我只需要说"显示这个按钮"
function App() {
  return <button>点击我</button>
}
// React会自动处理DOM操作
```

## 2. 什么是 JSX？

**答案：**

JSX 是 JavaScript XML 的缩写，是 React 中用来描述 UI 的语法扩展。它看起来像 HTML，但实际上是 JavaScript。

**核心要点：**

- JSX 最终会被编译成 `React.createElement()` 调用
- 可以在 JSX 中使用 `{}` 嵌入 JavaScript 表达式
- JSX 必须有一个根元素

**举例：**

```jsx
// JSX 写法
const element = <h1>Hello, {name}!</h1>

// 编译后的JavaScript
const element = React.createElement('h1', null, 'Hello, ', name, '!')

// 嵌入表达式
const age = 18
const message = <p>我{age >= 18 ? '成年了' : '未成年'}</p>
```

## 3. 什么是组件（Component）？函数组件和类组件有什么区别？

**答案：**

组件是 React 应用的构建块，是可复用的 UI 片段。

**函数组件：**

```jsx
// 简单、推荐使用
function Welcome(props) {
  return <h1>Hello, {props.name}</h1>
}

// 或使用箭头函数
const Welcome = (props) => {
  return <h1>Hello, {props.name}</h1>
}
```

**类组件：**

```jsx
// 较旧的写法
class Welcome extends React.Component {
  render() {
    return <h1>Hello, {this.props.name}</h1>
  }
}
```

**主要区别：**
| 函数组件 | 类组件 |
|---------|--------|
| 语法简洁 | 语法复杂 |
| 使用 Hooks 管理状态 | 使用 this.state |
| 没有生命周期方法 | 有生命周期方法 |
| **现代 React 推荐** | 逐渐被淘汰 |

## 4. 什么是 Props？

**答案：**

Props（properties 的缩写）是组件的输入参数，用于父组件向子组件传递数据。

**核心特点：**

- **只读的**：子组件不能修改 props
- **单向数据流**：数据从父组件流向子组件

**举例：**

```jsx
// 父组件传递props
function App() {
  return <UserCard name="张三" age={25} isVIP={true} />
}

// 子组件接收props
function UserCard(props) {
  return (
    <div>
      <h2>{props.name}</h2>
      <p>年龄：{props.age}</p>
      <p>{props.isVIP ? 'VIP用户' : '普通用户'}</p>
    </div>
  )
}

// 使用解构更简洁
function UserCard({ name, age, isVIP }) {
  return (
    <div>
      <h2>{name}</h2>
      <p>年龄：{age}</p>
      <p>{isVIP ? 'VIP用户' : '普通用户'}</p>
    </div>
  )
}
```

## 5. 什么是 State？

**答案：**

State 是组件内部的数据状态，当 state 改变时，组件会重新渲染。

**核心特点：**

- **私有的**：只属于当前组件
- **可变的**：可以通过 setState 更新
- **异步更新**：React 会批量处理 state 更新

**举例：**

```jsx
import { useState } from 'react'

function Counter() {
  // 声明state：[当前值, 更新函数]
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>点击了 {count} 次</p>
      <button onClick={() => setCount(count + 1)}>点击+1</button>
    </div>
  )
}

// 多个state
function Form() {
  const [name, setName] = useState('')
  const [age, setAge] = useState(0)

  return (
    <div>
      <input value={name} onChange={(e) => setName(e.target.value)} />
      <input value={age} onChange={(e) => setAge(e.target.value)} />
    </div>
  )
}
```

**Props vs State：**
| Props | State |
|-------|-------|
| 从父组件传入 | 组件内部管理 |
| 只读 | 可修改 |
| 类似函数参数 | 类似函数内的变量 |

## 6. 什么是 React Hooks？常用的有哪些？

**答案：**

Hooks 是 React 16.8 引入的特性，让函数组件可以使用 state 和其他 React 特性。

**常用 Hooks：**

**1. useState - 状态管理**

```jsx
const [count, setCount] = useState(0)
```

**2. useEffect - 副作用处理（生命周期）**

```jsx
useEffect(() => {
  // 组件挂载或更新时执行
  document.title = `点击了${count}次`

  // 返回清理函数（可选）
  return () => {
    console.log('组件卸载或下次effect前执行')
  }
}, [count]) // 依赖项数组
```

**3. useRef - 获取 DOM 引用或保存可变值**

```jsx
const inputRef = useRef(null)
const handleClick = () => {
  inputRef.current.focus() // 聚焦输入框
}
```

**4. useContext - 跨层级传递数据**

```jsx
const theme = useContext(ThemeContext)
```

**5. useMemo - 缓存计算结果**

```jsx
const expensiveValue = useMemo(() => {
  return computeExpensiveValue(a, b)
}, [a, b])
```

**6. useCallback - 缓存函数**

```jsx
const handleClick = useCallback(() => {
  console.log(count)
}, [count])
```

## 7. 什么是虚拟 DOM（Virtual DOM）？

**答案：**

虚拟 DOM 是 React 在内存中维护的一个轻量级的 DOM 树副本，是一个 JavaScript 对象。

**工作原理：**

1. **初始渲染**：React 创建虚拟 DOM 树，然后生成真实 DOM
2. **状态更新**：创建新的虚拟 DOM 树
3. **Diff 算法**：对比新旧虚拟 DOM，找出差异
4. **最小化更新**：只更新变化的真实 DOM 节点

**为什么需要虚拟 DOM？**

- **提高性能**：减少真实 DOM 操作（DOM 操作很慢）
- **批量更新**：React 可以合并多次更新
- **跨平台**：虚拟 DOM 可以渲染到不同平台（Web、Native、Canvas 等）

**举例说明：**

```jsx
// 假设有100个列表项，只改变了第50项的文本
// 传统方式：需要重新渲染整个列表
// React方式：只更新第50项对应的真实DOM节点

function List({ items }) {
  return (
    <ul>
      {items.map((item) => (
        <li key={item.id}>{item.text}</li>
      ))}
    </ul>
  )
}
```

## 8. 什么是生命周期？

**答案：**

生命周期是组件从创建到销毁的整个过程。在函数组件中，使用 `useEffect` 来模拟生命周期。

**三个阶段：**

**1. 挂载（Mount）- 组件创建**

```jsx
useEffect(() => {
  console.log('组件挂载了 - 类似componentDidMount')
  // 执行初始化操作：获取数据、订阅事件等
}, []) // 空依赖数组，只执行一次
```

**2. 更新（Update）- 状态或 props 改变**

```jsx
useEffect(() => {
  console.log('count改变了 - 类似componentDidUpdate')
  // count改变时执行
}, [count]) // 依赖count
```

**3. 卸载（Unmount）- 组件销毁**

```jsx
useEffect(() => {
  // 订阅
  const subscription = subscribe()

  return () => {
    // 清理函数 - 类似componentWillUnmount
    console.log('组件卸载了')
    subscription.unsubscribe() // 取消订阅
  }
}, [])
```

**完整示例：**

```jsx
function UserProfile({ userId }) {
  const [user, setUser] = useState(null)

  useEffect(() => {
    console.log('1. 组件挂载或userId变化')

    // 获取用户数据
    fetchUser(userId).then(setUser)

    return () => {
      console.log('2. 清理：userId变化前或组件卸载前')
    }
  }, [userId])

  return <div>{user?.name}</div>
}
```

## 9. 什么是事件处理？React 中的事件处理有什么特点？

**答案：**

React 中的事件处理与原生 DOM 事件类似，但有一些区别。

**React 事件的特点：**

1. **驼峰命名**：`onClick` 而不是 `onclick`
2. **传递函数**：而不是字符串
3. **合成事件**：React 封装了原生事件，跨浏览器兼容
4. **阻止默认行为**：必须显式调用 `e.preventDefault()`

**举例：**

```jsx
function Example() {
  // ✅ 正确：传递函数
  const handleClick = (e) => {
    e.preventDefault() // 阻止默认行为
    e.stopPropagation() // 阻止冒泡
    console.log('按钮被点击')
  }

  // 传递参数
  const handleDelete = (id) => {
    console.log('删除', id)
  }

  return (
    <div>
      {/* 方式1：直接传递函数 */}
      <button onClick={handleClick}>点击</button>

      {/* 方式2：箭头函数传递参数 */}
      <button onClick={() => handleDelete(123)}>删除</button>

      {/* 方式3：bind传递参数 */}
      <button onClick={handleDelete.bind(null, 123)}>删除</button>

      {/* ❌ 错误：不要这样写 */}
      <button onClick={handleClick()}>错误</button>
      {/* 这会立即执行函数，而不是等点击时执行 */}
    </div>
  )
}

// 表单事件
function Form() {
  const [value, setValue] = useState('')

  const handleSubmit = (e) => {
    e.preventDefault() // 阻止表单提交
    console.log('提交的值:', value)
  }

  return (
    <form onSubmit={handleSubmit}>
      <input value={value} onChange={(e) => setValue(e.target.value)} />
      <button type="submit">提交</button>
    </form>
  )
}
```

## 10. 什么是 Key 属性？为什么列表渲染需要 key？

**答案：**

Key 是 React 用来识别列表中每个元素的唯一标识，帮助 React 高效地更新虚拟 DOM。

**为什么需要 key？**

没有 key 时，React 不知道哪个元素变了，只能重新渲染所有元素。
有了 key，React 可以精确知道哪些元素被添加、删除或移动。

**举例：**

```jsx
// ❌ 错误：没有key
function List({ items }) {
  return (
    <ul>
      {items.map((item) => (
        <li>{item}</li>
      ))}
    </ul>
  )
}

// ❌ 错误：使用index作为key（列表会变化时）
function List({ items }) {
  return (
    <ul>
      {items.map((item, index) => (
        <li key={index}>{item}</li>
      ))}
    </ul>
  )
}

// ✅ 正确：使用唯一的id作为key
function List({ items }) {
  return (
    <ul>
      {items.map((item) => (
        <li key={item.id}>{item.name}</li>
      ))}
    </ul>
  )
}
```

**Key 的规则：**

1. **唯一性**：兄弟节点中 key 必须唯一
2. **稳定性**：不要使用随机数，每次渲染都会变
3. **可预测性**：同一个元素的 key 不应该改变

**使用 index 作为 key 的问题：**

```jsx
// 假设初始列表：['A', 'B', 'C']
// 渲染为：<li key={0}>A</li>, <li key={1}>B</li>, <li key={2}>C</li>

// 在开头插入'X'后：['X', 'A', 'B', 'C']
// 使用index作为key会渲染为：
// <li key={0}>X</li>, <li key={1}>A</li>, <li key={2}>B</li>, <li key={3}>C</li>

// React会认为：
// - key={0} 的内容从'A'变成了'X'（需要更新）
// - key={1} 的内容从'B'变成了'A'（需要更新）
// - key={2} 的内容从'C'变成了'B'（需要更新）
// - 新增了 key={3} 的'C'

// 实际上只是在开头插入了一个元素，但React更新了所有元素！

// 使用唯一id作为key：
// 初始：[{id:1, name:'A'}, {id:2, name:'B'}, {id:3, name:'C'}]
// 插入后：[{id:4, name:'X'}, {id:1, name:'A'}, {id:2, name:'B'}, {id:3, name:'C'}]
// React会知道只需要插入一个新元素，其他元素不变
```

**什么时候可以使用 index 作为 key？**

- 列表是静态的，不会改变
- 列表不会被重新排序或过滤
- 列表项没有 id
